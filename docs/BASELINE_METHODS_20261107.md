# Baseline methods and provenance

The common interface is `research/reliability_20261106/baselines.py`. Inputs carry a question, shared initial draft, and frozen passages. Callbacks inject the existing generator, claim verifier, NLI engine or versioned compiled graph. Each output retains prompts, response text, timings, call counts, status and empty human factuality labels. A provider failure is never a correct abstention. Budgets reject oversized prompts or exhausted requests before another model call.

Plain generation reuses the actual original draft. Self critique asks the same model to review that draft without evidence. Basic RAG answers from the frozen passages. RAG with claim verification withholds unless a supplied verifier returns a nonempty all-verified report set. Graph adapters require an explicitly versioned callback and cannot silently substitute a simplified controller. The full prospective graph comparison is not completed in this revision.

The SelfCheck-style adapter draws three fresh answers at temperature 1.0 and uses the project's NLI model to score contradiction for each draft sentence against each sample. It averages contradiction scores and does not release or withhold at an invented threshold. The authors' maintained code includes additional scoring variants and a different NLI model; this small-sample adapter is not an exact reproduction. Source: [official SelfCheckGPT implementation](https://github.com/potsawee/selfcheckgpt) and [EMNLP 2023 paper](https://aclanthology.org/2023.emnlp-main.557/).

The CoVe-style adapter plans up to three verification questions, asks each separately without the draft or preceding answers, and revises the draft using the checks. It follows the factored information separation, but uses generic prompts and the project model instead of the original experimental setup. Source: [Dhuliawala et al., ACL Findings 2024](https://aclanthology.org/2024.findings-acl.212/).

The RARR-style adapter generates up to three research questions, ranks up to three passages by lexical overlap within the shared frozen pool, judges agreement and requests a minimal edit for unsupported content. It does not use the original web search, attribution report selection or original editor prompts/model. It is a constrained research-and-revision approximation. Sources: [Gao et al., ACL 2023](https://aclanthology.org/2023.acl-long.910/) and [official implementation](https://github.com/anthonywchen/RARR).

The pilot uses Groq `openai/gpt-oss-120b`, the same named model as the historical generator. It is not contemporaneous with the historical run, so hosted revisions and transient failures are uncontrolled. The shared evidence pool also depends on the original graph's retrieval and is not an independent search comparison. All whole-answer and preservation judgments await independent annotation. Partial pilot outputs must not be used to rank methods.
