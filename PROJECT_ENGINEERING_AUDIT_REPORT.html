4. Verifier Agent Detailed Analysis

The Verifier Agent is the core evidence-retrieval and fact-checking engine of HalluciGuard.

Subsystem Components

  1. API Server (api/main.py): Built with FastAPI. Listens on port 8002. Exposes /verify, /health, /domains, /metrics.
  2. Pipeline Orchestrator (api/pipeline.py): Executes a sequential 9-stage verification flow:
  3. Stage 1: Domain Validation (routers/domain_validator.py)
  4. Stage 2: Claim Decomposition & Normalization (claims/claim_decomposer.py, claims/claim_normalizer.py)
  5. Stage 3: Query Expansion (routers/query_expander.py)
  6. Stage 4: Multi-Source Evidence Retrieval (adapters/registry.py)
  7. Stage 5: Aggregation & Deduplication (aggregation/aggregator.py, aggregation/duplicate_remover.py)
  8. Stage 6: Cross-Encoder Reranking (rerankers/cross_encoder.py)
  9. Stage 7: Natural Language Inference (nli/entailment.py)
  10. Stage 8: Evidence & Conflict Scoring (scorers/evidence_scorer.py, scorers/conflict_resolver.py)
  11. Stage 9: Citation & Response Formatting (formatters/citation_formatter.py, formatters/response_formatter.py)
  12. Domain Adapters (adapters/): Live adapters for Healthcare, Cybersecurity, Finance, AI Research, Legal, General. Stubs handle 18 secondary domains.
  13. Caching Subsystem (cache/sqlite_cache.py): SQLite cache (verification_cache.db) storing query hashes and evidence items (TTL: 24h).
  14. Model Lifecycle Manager (models/model_manager.py): Singleton managing lazy loading/unloading of HuggingFace models.
  15. Domain Intelligence Taxonomy (models/domain_intelligence.py): Operates on config/domain_intelligence.yaml, supporting 35 domain classifications.
  16. Scoring Engine (scorers/): Implements Recency Decay, Source Reliability Weighting (config/credibility.yaml), and 2:1 Contradiction-to-Support arbitration.
