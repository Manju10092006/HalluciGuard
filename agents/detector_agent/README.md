# 🛡️ HalluciGuard Detector Agent

> The **Detector Agent** is the first component of the HalluciGuard multi-agent framework. It evaluates the reliability of Large Language Model (LLM) responses and estimates the likelihood of hallucinations before passing the response to downstream agents.

---

# 📖 Overview

HalluciGuard is a multi-agent system designed to detect, verify, and correct hallucinations generated by Large Language Models.

The **Detector Agent** is responsible for:

- Estimating the confidence of an LLM response.
- Detecting potential hallucinations using multiple complementary signals.
- Producing a calibrated confidence score and risk level.
- Forwarding structured results to the Verifier, Judge, Corrector, and Memory agents.

Unlike traditional hallucination detectors that rely on a single metric, this implementation combines multiple uncertainty and consistency signals to improve robustness.

It **does not verify or correct responses.**

# 🔍 Detection Signals

The Detector Agent combines four complementary signals.

## 1. Token Probability

Measures the confidence of the language model while generating each token.

Low confidence generally indicates a higher probability of hallucination.

---

## 2. Predictive Entropy

Measures uncertainty in the generated response.

Higher entropy suggests greater uncertainty.

---

## 3. Semantic Similarity

Measures semantic consistency between the response and supporting context.

Lower similarity indicates that the generated content may not be supported.

---

## 4. Self-Consistency

For analytical queries, multiple reasoning paths are generated and compared.

This signal is executed only when the intelligent gating mechanism determines additional verification is beneficial.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Manju10092006/HalluciGuard.git
cd HalluciGuard
```

---

## Install Dependencies

Install the project dependencies:

```bash
pip install -r requirements.txt
```

If your environment uses a virtual environment:

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt
```

---

# ▶️ Running the Detector Agent

Navigate to the Detector Agent folder:

```bash
cd agents/detector_agent
```

Run the application (adjust the entry point if different):

```bash
python detector.py
```

or, if a FastAPI server is provided:

```bash
uvicorn api.main:app --reload
```

---

# 🔗 How Other Agents Can Use It

The Detector Agent is designed to be consumed by:

- Verifier Agent
- Judge Agent
- Corrector Agent
- Memory Agent

Example:

```python
from detector_agent.detector import DetectorAgent

detector = DetectorAgent()

result = detector.detect(
    query="Who discovered gravity?",
    response="Isaac Newton discovered gravity."
)

print(result)
```
